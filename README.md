# Personal Library

Учебное приложение для учёта книг и комиксов в личной библиотеке.
Проект позволит вести каталог публикаций, отмечать наличие экземпляра
и отслеживать статус чтения.

## Текущее состояние

Реализована модель публикации `Publication`, которая содержит:

- название, тип публикации и автора;
- серию и номер тома — при наличии;
- признак владения экземпляром;
- статус чтения.

При создании публикации проверяются обязательные поля, тип публикации,
статус чтения и положительный номер тома. Пробелы по краям названия,
имени автора и названия серии удаляются.

Статус чтения не зависит от владения: публикацию можно отметить
прочитанной, даже если её нет в собственности.

Реализован класс `Library`, который позволяет:

- добавлять публикации в библиотеку;
- получать список всех публикаций;
- искать публикации по части названия без учёта регистра.

Данные хранятся в памяти и теряются после завершения программы.

Для модели публикации и библиотеки написано 20 автоматических тестов.

## Установка

Требуется Python 3.10 или новее.

Клонировать репозиторий и перейти в папку проекта:

```powershell
git clone https://github.com/6rkdtui/personal-library.git
cd personal-library
```

Создать и активировать виртуальное окружение в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Установить зависимости для разработки:

```powershell
python -m pip install -r requirements-dev.txt
```

## Тестирование

Из корня проекта выполнить:

```powershell
python -m pytest -q
```
